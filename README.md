# 2CRM

Небольшая CRM для строительной компании: постановщик ведёт объекты и задачи, исполнитель выполняет назначенные ему задачи и отправляет результат на проверку.

Подготовлены каркас и анализ существующих open source решений. Каркас запускается и собирается; функции CRM, миграции и демонстрационные пользователи ещё не реализованы.

## Запуск

Нужен Node.js 24.22 или новее. Проверено на Node.js 24.22.1.

```powershell
npm ci --ignore-scripts
npm run dev
```

Локальный адрес: `http://127.0.0.1:5173`. Для подключения скопируйте `.env.example` в `.env.local` и заполните URL своего Supabase и publishable key.

```powershell
npm run typecheck
npm run build
npm run check:supabase
```

`check:supabase` предназначен для текущего пустого проекта: проверяет доступ к REST API через ожидаемую ошибку отсутствующей проверочной таблицы и читает открытые настройки Auth. Он не проверяет вход пользователя, RLS или переходы статусов.

В `.env.local` находятся только публичные параметры клиента. Секретные ключи не нужны для браузерного приложения. Все `.env` исключены из Git, кроме шаблона `.env.example`.

## Стек

- React и TypeScript, Vite для разработки и сборки.
- Ant Design: готовые формы, таблицы, диалоги и уведомления.
- React Router в декларативном режиме для пяти экранов.
- Supabase Auth для входа по email/паролю, PostgreSQL для данных и правил доступа.
- Для будущих интеграционных проверок: встроенный `node:test` и реальные обращения к API от разных пользователей. На Windows запуск без изоляции в дочерних процессах.
- Для публикации планируется Vercel со статической сборкой `dist`. Проект на Vercel пока не создан.

Версии зафиксированы в `package.json` и `package-lock.json`. Redux, отдельный сервер, ORM и дополнительная библиотека форм на этом этапе не требуются: Ant Design предоставляет формы, Supabase — клиент и API.

Исходников Docker в проекте нет, локальный стек Supabase в Docker не запускался.
